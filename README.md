# TopoMorph

Code for the paper "TopoMorph: fast, nearly fold-free learned registration of hippocampal MRI and its accuracy cost against a tuned ANTs SyN" (Imran, King Fahd University of Petroleum and Minerals; submitted to Computerized Medical Imaging and Graphics).

Archived deposit: https://doi.org/10.5281/zenodo.24311301

## Status

This repository is being populated. It will hold the training and evaluation code, the configuration file of every reported run, the test and IXI pair lists, per-pair result files, and the scripts that regenerate every table and figure. Trained checkpoints are in the Zenodo deposit.

## Data

MSD Task04 Hippocampus (CC BY-SA 4.0) and IXI (CC BY-SA 3.0) are public and are not redistributed here.
